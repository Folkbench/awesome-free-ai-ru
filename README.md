# Бесплатные ИИ-ресурсы для русскоязычных разработчиков · Folkbench RU

**6 ресурсов, а не 6 бесплатных API:** один условно применимый облачный freemium для резидентов РФ, два локальных движка и три набора весов моделей. Проверено чтением официальных источников 23 ноября 2026 (Asia/Shanghai).

## Бесплатно — в каком смысле?

**Облачный бесплатный пакет** ограничен аккаунтом, регионом, сроком и правилами провайдера. **Свободный локальный движок** запускает модели, но не выдаёт токены. **Открытые веса** нужны движку; компьютер, электричество и загрузка не становятся бесплатными. Эти категории не суммируются как токены и не ранжируются вместе.

У локальных ресурсов нет проверки страны облачного API во время самостоятельного вывода. Это не гарантия доступа к GitHub/Hugging Face из каждой сети РФ и не юридическое заключение. Если официальная региональная гарантия или требование карты не опубликованы, пишем «неизвестно», а не «работает всем».
