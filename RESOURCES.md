## Облачный бесплатный пакет — с условиями

<a id="gigachat-freemium"></a>

### GigaChat API · Freemium

**Для чего:** Личные некоммерческие API-эксперименты резидента РФ.

**Бесплатность / квота:** 365 000 000 текстовых токенов: Lite 250 млн, Pro 40 млн, Max 25 млн, Ultra 50 млн. Это общий пакет по тарифной странице, не ежемесячная выдача.

**Срок:** 12 месяцев по опубликованному тарифу; начало срока и наличие пакета уточните в своём проекте.

**Скорость / лимиты:** Один поток генерации для физлиц.

**Регион:** Оферта для физлиц: полностью дееспособный резидент РФ от 18 лет. Это не предложение для всех русскоязычных пользователей мира.

**Условия / лицензия:** Пользовательское соглашение GigaChat; бесплатные результаты только для личных некоммерческих целей.

**Что важно до запуска:** Страница тарифов адресована действующим клиентам и отдельно направляет новых плательщиков на cloud.ru с 01.09.2026. Наличие именно этого пакета у нового аккаунта нами не проверено; подтвердите в кабинете до интеграции. Бесплатный доступ может быть прекращён по соглашению. Нужны регистрация и проект; быстрый старт указывает сертификаты НУЦ Минцифры.

**Статус проверки:** Прочитаны источники; регистрация, загрузка весов и API-тесты не выполнялись.

## Локальные движки — без выдачи облачных токенов

<a id="ollama-local"></a>

### Ollama · только локальный режим

**Для чего:** Простой запуск скачанной модели на своём компьютере и локальный API.

**Бесплатность / квота:** Нет выдачи облачных токенов: бесплатное ПО для локального вывода.

**Срок:** Таймер бесплатного облачного пакета не применяется.

**Скорость / лимиты:** Зависит от модели, памяти, контекста и компьютера; облачная квота не применяется.

**Регион:** Для локального вывода не нужен аккаунт облачного API или проверка его страны. Отдельной гарантии скачивания из РФ в прочитанном источнике нет; доступ к хостингу, местное право и условия лицензии проверяются пользователем.

**Карта:** Не нужна для локального вывода; документация разрешает пропустить создание API-ключа.

**Условия / лицензия:** MIT для Ollama; у каждой модели своя лицензия.

**Что важно до запуска:** Выберите local, а не cloud. Компьютер, электричество, место для весов и сеть для загрузки оплачиваются пользователем. Бесплатность ПО не распространяется автоматически на облако.

**Статус проверки:** Прочитаны источники; регистрация, загрузка весов и API-тесты не выполнялись.

### llama.cpp · локальный вывод

**Для чего:** Локальный C/C++-движок, GGUF и собственный совместимый API-сервер.

**Бесплатность / квота:** Нет выдачи токенов; свободное ПО без платы за каждый локальный запрос.

**Срок:** Не ограничено сроком пробного облачного пакета.

**Скорость / лимиты:** Определяется вашим оборудованием и конфигурацией; общего бесплатного RPM нет.

**Регион:** Для локального вывода не нужен аккаунт облачного API или проверка его страны. Отдельной гарантии скачивания из РФ в прочитанном источнике нет; доступ к хостингу, местное право и условия лицензии проверяются пользователем.

**Карта:** Не нужна для самостоятельного локального запуска; хостинг чужого сервера — отдельная услуга.

**Условия / лицензия:** MIT для движка; лицензия весов отдельная.

**Что важно до запуска:** Нужно самостоятельно подобрать модель и память. Не открывайте локальный API-сервер в интернет без защиты. Движок сам по себе не содержит все модели.
